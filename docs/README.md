# docs/

Current, durable reference for BifrostQL that sits outside the website:

- `AppSchemaDetection.md`, `CreatingCustomDetectors.md`, `WordPressSchemaBundle.md`: app-schema detection and writing detectors.
- `file-storage-system.md`: the file storage model and bucket metadata.
- `DatabasePerformanceComparison.md`: benchmark analysis the benchmarks README links to.
- `server-secured-operations.md`: the design record behind server-secured operations (the site guide links to it).
- `fleet/prompts/`: the headless review gate contract `.worktrack/templates.json` loads.
- `solutions/`: compound-engineering learnings.

The website (Astro Starlight, canonical user docs) is in `site/`; `docs-research/` is exploratory.
Plans, specs and in-flight work are tracked in worktrack workspace `bifrostql`. A plan a task
cites is committed under `docs/plans/` while the task is open, and removed once it lands.
